# Screenshots

Put PNG/GIF captures here and reference them from the top-level README with
relative paths, e.g. `![Terminal](docs/screenshots/terminal-split.png)`.

Relative paths (not pasted CDN URLs) are preferred: the images are version
controlled, survive a clone, and render offline.

Suggested shots, in order of impact:
1. `terminal-split.png` — a split-pane session (the core product)
2. `sftp.png` — dual-pane transfer mid-drag
3. `host-key.png` — the fingerprint prompt (shows the security posture)
4. `ai-panel.png` — the assistant with a command chip

For the drag-to-transfer and broadcast features, a short GIF sells them far
better than a still — capture with ScreenToGif (free) or Xbox Game Bar
(Win+G). Keep each under ~3 MB so the README stays light.

Before committing a capture, check it for anything sensitive: real hostnames,
internal IPs, usernames, or on-screen output. Use the documentation-range
example hosts, or blur them.
